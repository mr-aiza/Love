# ورود خصوصی خانه‌ی ما — بدون صفحه راه‌اندازی

این نسخه صفحه «راه‌اندازی اولیه» را کاملاً حذف می‌کند. نام‌های کاربری و رمزها را در Cloudflare Worker تعریف می‌کنید و حساب‌ها و فضای مشترک در اولین تلاش ورود، خودکار ساخته می‌شوند.

## ۱) تعریف رمزها در Cloudflare

در Cloudflare وارد Worker با نام `ourhome` شوید و به `Settings → Variables and Secrets` بروید. در بخش **Production** این موارد را داشته باشید:

- `ORIGIN` (Variable): `https://mr-aiza.github.io`
- `USER_424_PASSWORD` (Secret): رمز دلخواه حساب علیرضا
- `USER_626_PASSWORD` (Secret): رمز دلخواه حساب صبا

برای ساخت هر دو Secret از `Add variable` استفاده کنید و نوع را **Secret** انتخاب کنید. مقدارها را بدون فاصله‌ی اضافه وارد کنید. اگر می‌خواهید رمز هر دو حساب یکسان باشد، برای هر دو Secret مقدار `دوست دارم` را قرار دهید. نام کاربری‌ها ثابت هستند: `424` و `626`.

## ۲) بررسی KV

در `Settings → Bindings` باید اتصال `KV namespace` با نام دقیق `DB` وجود داشته باشد (همان اتصال فعلی شما).

## ۳) انتشار Worker و سایت

1. کد فایل `worker.js` این بسته را جایگزین کد Worker فعلی کنید و `Deploy` بزنید.
2. فایل‌های این بسته را در ریشه‌ی مخزن GitHub `mr-aiza/Love` بارگذاری و Commit کنید.
3. بعد از Deploy، سایت را باز کنید. هیچ دکمه یا صفحه‌ای برای راه‌اندازی اولیه وجود ندارد.
4. در اولین ورود معتبر با `424` یا `626`، Worker به‌صورت خودکار حساب‌ها و فضای مشترک را ایجاد می‌کند؛ ورودهای بعدی با همان Secrets اعتبارسنجی می‌شوند.

## نکات امنیتی

- رمزها در Cloudflare به‌صورت Secret نگهداری می‌شوند و در KV به‌صورت هش PBKDF2 ذخیره می‌شوند.
- تا قبل از ورود موفق، محتوای سایت با صفحه ورود پوشانده می‌شود و پیام «فضولی نکن!» نمایش داده می‌شود.
- رمزهای دو حساب را در پیام یا اسکرین‌شات ارسال نکنید.
- اگر حساب‌ها از قبل در KV ساخته شده‌اند، تغییر Secretها به‌تنهایی رمزهای ذخیره‌شده را تغییر نمی‌دهد؛ برای تغییر رمز موجود باید رکوردهای حساب را به روش امن بازنشانی کرد.
